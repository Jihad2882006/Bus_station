# 🚌 نظام محطة إكسبريس لحجز تذاكر الحافلات وإدارة المحطة
> **Express Bus Station & Booking Management System (Full Stack: Python + SQLite + Vanilla JS + HTML5/CSS3)**

نظام ويب متكامل مصمم خصيصاً لمحطات الأتوبيس وشركات النقل الجماعي في جمهورية مصر العربية، يجمع بين:
1. **العميل (الراكب):** البحث بين جميع محافظات مصر، اختيار المقاعد من كروكي الحافلة، ودفع الأجرة إلكترونياً، واستخراج تذكرة رقمية بالـ QR Code.
2. **السائق (الكابتن):** متابعة خط السير، كشف ركاب الرحلة، وتأكيد صعود الراكب عند الباب.
3. **إدارة المحطة (محمية):** مراقبة الإيرادات المالية، جدولة الرحلات بين المحافظات، ومتابعة الأسطول.

## 🗺️ المحافظات الـ 27 المدعومة في النظام:
1. **القاهرة الكبرى:** القاهرة (رمسيس/الترجمان/عبود)، الجيزة (المنيب/أكتوبر)، القليوبية (بنها).
2. **محافظات القناة وسيناء:** بورسعيد، الإسماعيلية، السويس، جنوب سيناء (شرم الشيخ، دهب، طور سيناء)، شمال سيناء (العريش).
3. **محافظات الدلتا والوجه البحري:** الإسكندرية (محرم بك)، الدقهلية (المنصورة)، الغربية (طنطا/المحلة)، الشرقية (الزقازيق)، المنوفية (شبين الكوم)، دمياط (رأس البر)، كفر الشيخ، البحيرة (دمنهور)، مطروح (مرسى مطروح/العلمين).
4. **محافظات الصعيد والبحر الأحمر والوادي الجديد:** البحر الأحمر (الغردقة/مرسى علم)، الفيوم، بني سويف، المنيا، أسيوط، سوهاج، قنا، الأقصر، أسوان، الوادي الجديد (الخارجة).

## 🔌 نقاط نهاية الـ API (Backend Endpoints):
- `POST /api/auth/register` : إنشاء حساب جديد (الاسم الأول والأخير، الهاتف، الجيميل، العنوان، كود الإدارة).
- `POST /api/auth/login` : تسجيل الدخول برقم الهاتف أو الجيميل وكلمة المرور.
- `GET /api/trips` : جلب الرحلات مع إمكانية الفلترة بمحطة المغادرة والوصول.
- `GET /api/trips/{id}` : تفاصيل المقاعد المحجوزة والمتاحة لرحلة معينة.
- `POST /api/trips` : جدولة رحلة جديدة بين المحافظات (خاص بالإدارة).
- `DELETE /api/trips/{id}` : حذف أو إلغاء رحلة (خاص بالإدارة).
- `POST /api/bookings` : حجز مقاعد وسداد الأجرة وإصدار كود PNR وتذكرة QR Code.
- `GET /api/bookings` : سجل الحجوزات الكامل لمتابعة الدفع.
- `POST /api/driver/checkin` : تأكيد صعود الراكب للحافلة (خاص بالسائق).
- `POST /api/driver/trip-status` : تحديث حالة الرحلة (جاهزة / في الطريق / انتهت).
- `GET /api/admin/stats` : إحصائيات الإيرادات والتذاكر المباعة من قاعدة البيانات.
